# 홍작 로고 및 차 이미지
기존 홍작 로고 원본 파일은 현재 대화에서 확보하지 못했으므로 임의로 새 로고를 제작하지 않았습니다.
원본 SVG 또는 고해상도 PNG를 이 폴더에 넣고 `../js/config.js`의 `logoPath`를 `./assets/hongjak-logo.svg` 등으로 설정하면 표시됩니다. 원본이 없을 때는 텍스트 워드마크를 표시합니다.
차 사진도 이 폴더에 추가한 뒤 차 등록 화면에서 `assets/파일명.jpg`를 입력할 수 있습니다. 외부 HTTPS 이미지도 사용할 수 있습니다. 이미지 자체의 웹 업로드 기능은 포함되지 않습니다.
